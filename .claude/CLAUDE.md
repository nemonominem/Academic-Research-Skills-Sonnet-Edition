# Academic Research Skills — Sonnet Edition

A curated collection of three standalone skills for academic research workflows, pinned to `model: sonnet`:

## Skills Overview

| Skill | Purpose | Key Modes |
|-------|---------|-----------|
| `deep-research` | In-depth research exploration and synthesis | full, plan, socratic |
| `academic-paper` | Full paper writing pipeline (12 agents, 8 phases) | full, plan, outline, revision, abstract, lit-review, format-convert, citation-check, revision-coach, disclosure |
| `academic-paper-reviewer` | Multi-perspective peer review simulation (7 agents) | full, re-review, quick, methodology-focus, guided, calibration |

## User Workflow

1. **Explore a topic**: Use `deep-research` to gather and synthesize literature
2. **Write a paper**: Use `academic-paper` to draft from outline to final output (LaTeX/DOCX/PDF)
3. **Review your paper**: Use `academic-paper-reviewer` to get 5-perspective peer review (EIC + 3 reviewers + Devil's Advocate)

## Mode Selection Guidance

- **Not sure where to start?** Use `plan` mode in any skill — it guides you step by step
- **Quick review needed?** `academic-paper-reviewer quick` mode gives a 15-minute assessment
- **Need to parse reviewer comments?** `academic-paper revision-coach` mode structures unstructured feedback into a Revision Roadmap
- **Writing from scratch?** Start with `academic-paper plan` to build a chapter-by-chapter plan, then switch to `full` to draft
