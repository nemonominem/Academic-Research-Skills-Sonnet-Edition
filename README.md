# Academic Research Skills — Sonnet Edition

A lean, Sonnet-optimized fork of [academic-research-skills](https://github.com/Imbad0202/academic-research-skills) by Cheng-I Wu.

**What's different:**
- **All agents pinned to Sonnet** — no Opus 4.8 required
- **Stripped of pipeline infrastructure** — no integrity gates, CI scripts, claim-audit layer, or verification tooling
- **Preserved core research workflow** — Socratic dialogue, literature review, paper writing, structured peer review
- **~90% fewer files** — only the prompts and agents you need

## What you get

| Skill | Modes | Core use case |
|-------|-------|--------------|
| `deep-research` | full, quick, socratic, lit-review, fact-check, review | Exploration, literature review, Socratic guided thinking |
| `academic-paper` | full, plan, outline-only, revision, revision-coach, format-convert, disclosure | Paper writing, revision, formatting |
| `academic-paper-reviewer` | full, quick, guided, methodology-focus, re-review | Structured peer review |

## Quick start

```
# Socratic guided research
"Guide my research on [topic]"

# Full literature review
"Research [topic]"

# Write a paper (after research)
"Write a paper on [topic]"

# Review a paper
"Review this paper" (then paste your manuscript)
```

See each skill's `SKILL.md` for full mode lists and trigger keywords.
